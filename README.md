# Your Barber – אתר מספרת גברים

אתר סטטי (HTML + CSS + JavaScript), בלי צורך בהתקנות, שרת או מסד נתונים.

## מבנה הקבצים

```
barber-site/
├── index.html        ← כל התוכן והטקסטים של האתר
├── style.css         ← העיצוב (צבעים, פונטים, רספונסיביות)
├── main.js           ← הגדרות העסק (טלפון/וואטסאפ/כתובת) + אנימציות ותפריט
├── favicon.svg       ← האייקון שבלשונית הדפדפן
├── robots.txt        ← הנחיות לגוגל
└── sitemap.xml       ← מפת אתר לגוגל
```

## 1. הפעלה במחשב
לחיצה כפולה על `index.html` – האתר ייפתח בדפדפן. (צריך חיבור לאינטרנט כדי לטעון תמונות, פונטים ומפה.)

## 2. שינוי פרטים
| מה משנים | איפה |
|---|---|
| טלפון, מספר וואטסאפ, הודעה מוכנה, כתובת | ראש הקובץ `main.js` – אובייקט `CONFIG` |
| מחירים | `index.html` – חפשו `₪` (מופיע בכרטיסי השירותים ובמחירון) |
| שעות פעילות | `index.html` – חפשו `שעות פעילות` (וגם בפוטר וב-Schema בראש הקובץ) |
| שם העסק | `index.html` – חפשו `Barber` (כותרת, לוגו, פוטר, SEO) |
| תמונות | `index.html` – החליפו כתובות `src` / `data-full`. רקעים (Hero, מחירון, קביעת תור) נמצאים ב-`style.css` – חפשו `url(` |
| צבעים | `style.css` – משתני `:root` בראש הקובץ |

**מספר וואטסאפ:** 972 + המספר בלי ה-0 הראשון. לדוגמה 052-123-4567 ← `972521234567`.

**תמונות משלכם:** שימו את הקבצים בתיקייה `assets/` והפנו אליהם, למשל `src="assets/haircut1.jpg"`. מומלץ לדחוס ל-JPG/WebP ברוחב עד 1600px.

## 3. פרסום באינטרנט (חינם)
**Netlify (הכי קל):** היכנסו ל-app.netlify.com/drop וגררו את כל התיקייה `barber-site`. תקבלו כתובת חיה תוך שניות.
חלופות: Vercel, GitHub Pages, Cloudflare Pages.

## 4. חיבור דומיין
1. קנו דומיין (למשל ב-Namecheap, GoDaddy, או domain.co.il לסיומת ‎.co.il).
2. ב-Netlify: Site configuration → Domain management → Add a domain.
3. Netlify יציג רשומות DNS (A / CNAME) – העתיקו אותן לאזור ה-DNS אצל רשם הדומיין.
4. אחרי שהדומיין עובד (עד 24 שעות) – HTTPS מופעל אוטומטית.
5. החליפו `https://www.example.com/` בכתובת האמיתית בקבצים: `index.html`, `robots.txt`, `sitemap.xml`.

## 5. קידום בגוגל
- פתחו פרופיל עסק ב-Google Business Profile (הכי חשוב למספרה מקומית).
- הוסיפו את האתר ל-Google Search Console ושלחו את `sitemap.xml`.
